# AI 생성 및 협업을 위한 디자인 · 영상 · 개발 통합 프롬프트 용어집

**실무의 언어로 지시하고, 결과의 기준으로 검수하는 책.**

디자인·영상·개발에서 실제로 사용하는 용어를 AI에게 전달할 수 있는 구체적인 작업 명령으로 정리한 한국어 실무 사전입니다. 저작권자는 **이지섭**이며, **AI의 도움을 받아 작성**했습니다. 누구나 무료로 열람하고 개인 학습을 위해 다운로드할 수 있습니다.

## 어떤 책인가요?

“세련되게 만들어 줘”, “영화처럼 움직이게 해 줘”, “오류 없이 개발해 줘”라는 요청만으로는 필요한 작업을 정확히 전달하기 어렵습니다. 무엇을 바꾸려는지 알아도 그 작업의 이름을 모르면 AI에게 결과를 설명하고 수정 방향을 지정하기가 막막해집니다.

이 책은 그런 순간에 필요한 실무 용어를 찾아 쓰도록 구성했습니다. 글자 쌍의 간격을 바꾸는 **Kerning**, 카메라가 피사체에 다가가는 **Dolly In**, 반복 요청의 중복 효과를 제어하는 **Idempotency**처럼 분야별 개념을 정의·차이·실행·검수로 연결합니다.

## 용어 하나를 어떻게 설명하나요?

각 항목에는 **한글명·영문명**과 다음 여섯 가지 내용이 담겨 있습니다.

| 항목 | 읽고 실행할 내용 |
| --- | --- |
| 뜻·쓰임 | 개념의 정의와 이 작업이 필요한 상황 |
| 혼동 구분 | 비슷한 용어와의 차이, 적용 범위와 한계 |
| 실행 명령 | 대상과 행동을 지정한 구체적인 AI 요청 예시 |
| 설정·계약 | 단위, 제어값, 입력·출력, 버전과 작업 범위 |
| 검수 | 실제 파일과 동작에서 확인할 기준 |
| 수정 명령 | 결과가 어긋났을 때 바꿀 부분을 좁히는 후속 요청 |

## 이렇게 활용해 보세요

1. **무엇을 바꿀지는 알지만 이름을 모를 때:** 6~9쪽의 작업 의도별 찾아보기에서 시작하세요.
2. **용어를 알고 있을 때:** 영문 색인 187~194쪽 또는 한글 색인 195~202쪽에서 항목을 찾으세요.
3. **여러 작업을 묶어 요청할 때:** 166~177쪽의 제작 명령서를 바탕으로 대상·수치·파일 형식·검수 조건을 바꾸세요.
4. **결과를 수정할 때:** 해당 항목의 검수 기준으로 문제를 확인하고 수정 명령을 적용하세요.

기본 조합은 **대상 + 작업 + 관계·제약 + 설정 + 산출물 + 검수 기준**입니다.

> 예시: “제품에 접근하는 달리 인 샷을 만들되 제품의 형태와 크기는 유지하라. 배경의 시차가 자연스럽게 변하도록 하고, 생성된 결과에서 카메라 이동과 제품 자체의 확대를 구별해 확인하라.”

Midjourney, Stable Diffusion, Runway, ChatGPT, Claude 등에서 참고할 수 있습니다. 실제 지원 기능과 파라미터는 도구·모델·버전에 따라 다르며, 문구를 입력하는 것과 파일 속성이나 기능이 구현되는 것은 구별해야 합니다. 예시 수치는 작업 환경에 맞춰 조정하세요.
