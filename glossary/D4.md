# D4 · 색채·인쇄·출력 규격

[전체 목차](README.md) · [작업별 찾기](TASK_FINDER.md) · [PDF](../book/AI_Integrated_Prompt_Glossary_KO.pdf) · [이용 조건](../LICENSE.md)

> 화면의 색과 인쇄물의 색을 어떻게 구분해 전달할 것인가?

색은 값과 출력 조건이 함께 있어야 정의된다. 디지털 열람본과 인쇄 제출본을 혼동하지 말고 인쇄소의 실제 요구를 우선한다. 이 장의 mm·PPI 예시는 고정 규격이 아니라 계산과 확인 방법을 설명한다.

<a name="d4-01"></a>
## D4-01 · RGB와 CMYK

**RGB / CMYK** · PDF 29쪽

### 뜻·쓰임

RGB는 빛의 가산 혼합, CMYK는 인쇄 잉크의 감산 혼합에 쓰는 색 모델이다. 화면용 이미지와 인쇄용 파일의 작업·출력 조건을 구분할 때 사용한다.

### 혼동 구분

색 모델 이름만으로 정확한 색이 정의되지는 않는다. 같은 CMYK 값도 종이·잉크·프로파일에 따라 달라진다.

### 실행 명령

```text
웹 배너는 sRGB로, 인쇄 전단은 인쇄소가 지정한 CMYK 프로파일로 준비하라. 두 납품본의 색 변환과 교정 절차를 따로 기록하라.
```

### 설정·계약

웹 이미지를 무조건 CMYK로 변환하지 않는다. 인쇄 변환 시 선명한 파랑·초록처럼 재현 범위를 벗어나는 색을 확인한다.

### 검수

색 모드·프로파일·출력 매체가 맞고 변환 후 브랜드 색과 암부가 허용 범위인지 확인.

### 수정 명령

```text
‘원본과 똑같은 CMYK’ 대신 사용 종이·프로파일·교정 기준을 지정하라.
```

<a name="d4-02"></a>
## D4-02 · ICC 프로파일

**ICC Profile** · PDF 29쪽

### 뜻·쓰임

장치나 색공간의 색 표현 특성을 기술해 서로 다른 환경 사이의 색 변환을 돕는 데이터다. 이미지·모니터·인쇄기의 색을 일관되게 관리할 때 쓰인다.

### 혼동 구분

Assign은 숫자의 해석을 바꾸고 Convert는 외관을 유지하려 숫자를 변환한다. 임의 프로파일 할당은 색을 크게 바꿀 수 있다.

### 실행 명령

```text
원본의 임베디드 프로파일을 확인하고 목표 프로파일로 변환하라. 프로파일 없는 파일은 출처를 확인하고 가정을 보고하라.
```

### 설정·계약

원본·작업·출력 프로파일과 렌더링 인텐트를 기록한다. 색관리 없는 뷰어의 표시를 유일한 기준으로 삼지 않는다.

### 검수

임베딩 여부와 변환 전후 주요 색상, 중성 회색의 색 틀어짐을 색관리 환경에서 확인.

### 수정 명령

```text
잘못 할당한 프로파일 위에 보정을 쌓지 말고 올바른 원본 해석부터 복구하라.
```

<a name="d4-03"></a>
## D4-03 · 색역

**Color Gamut** · PDF 30쪽

### 뜻·쓰임

특정 색공간·장치·인쇄 조건에서 표현할 수 있는 색의 범위다. 넓은 색역 원본을 작은 색역으로 옮길 때 채도와 세부 표현이 달라질 수 있다.

### 혼동 구분

Dynamic Range는 밝기 범위이고 gamut은 색 범위다. wide gamut이 곧 HDR을 뜻하지 않는다.

### 실행 명령

```text
Display P3 원본을 웹 납품용 sRGB로 변환하고 범위 밖 색의 채도·명도 변화와 주요 브랜드 색을 비교하라.
```

### 설정·계약

출력 환경이 넓은 색역을 지원하는지 확인한다. 색역 경고만 보고 일괄 채도를 낮추지 말고 중요한 색의 보존 우선순위를 정한다.

### 검수

선명한 색이 평평하게 뭉치거나 여러 원색이 같은 색으로 수렴하지 않는지 확인.

### 수정 명령

```text
모든 채도를 높이는 대신 출력 색역 안에서 색 간 구별을 유지하도록 재조정하라.
```

<a name="d4-04"></a>
## D4-04 · 색상·채도·명도

**Hue / Saturation / Lightness** · PDF 30쪽

### 뜻·쓰임

색의 종류, 강도, 밝기 인상을 분리해 다루는 표현이다. 팔레트 조정과 상태 색 설계에서 ‘더 밝게’와 ‘덜 선명하게’를 구체화하는 데 쓰인다.

### 혼동 구분

HSL의 Lightness는 물리적 휘도나 WCAG 상대 휘도와 같지 않다. 같은 L 값의 노랑과 파랑이 같은 밝기로 보이지 않을 수 있다.

### 실행 명령

```text
브랜드의 파랑 계열 hue는 유지하고 보조 배경의 채도만 낮춰라. 텍스트 대비는 색 값이 아니라 실제 대비 계산으로 검증하라.
```

### 설정·계약

사용할 색 모델을 명시하고 명도 단계는 눈과 측정으로 함께 판단한다. 상태 의미를 색상 하나에만 의존하지 않는다.

### 검수

단색·회색조로 봐도 주요 정보와 상태가 구별되는지 확인.

### 수정 명령

```text
‘밝은 파랑’을 올려 썼다가 대비가 낮아지면 채도와 명도를 분리해서 수정하라.
```

<a name="d4-05"></a>
## D4-05 · 별색

**Spot Color** · PDF 31쪽

### 뜻·쓰임

CMYK 네 잉크의 혼합 대신 특정 색 잉크를 별도 판으로 인쇄하는 방식이다. 브랜드 색·금속색·형광색 같은 특수 인쇄에 사용한다.

### 혼동 구분

화면의 HEX 색이나 CMYK 근사치가 실제 별색 잉크와 같지 않다. 색상 이름을 붙였다고 분판이 자동으로 별색이 되지는 않는다.

### 실행 명령

```text
브랜드 로고를 인쇄소와 합의한 별색 스와치로 지정하고 별색 분판 유지 여부를 확인하라. 화면 검토용 근사색은 별도 표기하라.
```

### 설정·계약

잉크 이름·농도·종이·후가공을 함께 정한다. 별색 수는 인쇄 비용과 연결되므로 임의로 추가하지 않는다.

### 검수

분판 미리보기에서 예상한 별색 판이 남고 불필요한 유사 이름의 판이 생성되지 않는지 확인.

### 수정 명령

```text
비슷한 별색 이름을 하나로 통합하되 원본 잉크 계약과 실제 출력판을 비교하라.
```

<a name="d4-06"></a>
## D4-06 · 재단 여유

**Bleed** · PDF 31쪽

### 뜻·쓰임

최종 재단선 바깥으로 배경·이미지를 확장하는 영역이다. 재단 오차로 흰 틈이 생기는 것을 줄이며 인쇄물을 끝까지 색으로 채울 때 필요하다.

### 혼동 구분

안전 여백은 안쪽, bleed는 바깥쪽이다. 최종 문서 크기를 단순 확대하는 것과 다르다.

### 실행 명령

```text
완성 크기 148×210mm, 사방 3mm bleed를 예시로 설정하라. 배경은 bleed 끝까지 연장하고 글자는 재단선 안쪽 안전 영역에 둬라.
```

### 설정·계약

3mm는 관행적 예시이며 인쇄소 규격이 우선이다. 재단 표시를 bleed 안에 놓지 말고 최종 크기와 전체 아트워크 크기를 구별한다.

### 검수

네 변의 배경이 충분히 연장되고 글자·로고가 재단 위험 영역에 걸리지 않는지 확인.

### 수정 명령

```text
흰 여백을 프레임으로 가리지 말고 이미지와 배경 자체를 재단선 밖으로 확장하라.
```

<a name="d4-07"></a>
## D4-07 · 안전 여백

**Safe Area / Safe Margin** · PDF 32쪽

### 뜻·쓰임

재단·화면 가림·크롭으로 중요한 내용이 손상되지 않도록 안쪽에 확보하는 영역이다. 인쇄·영상·모바일에서 기준이 다르므로 적용 매체를 지정해야 한다.

### 혼동 구분

bleed나 padding과 목적이 다르다. 영상 플랫폼의 버튼 오버레이는 고정 인쇄 안전 여백과 동일하지 않다.

### 실행 명령

```text
세로 광고에서 제목·로고·CTA를 플랫폼 UI와 겹치지 않는 안전 영역에 배치하고, 실제 게시 화면 오버레이로 검토하라.
```

### 설정·계약

위·아래·좌·우 여백을 각각 정하고 매체 템플릿 버전을 기록한다. 정확한 플랫폼 규격은 납품 시 확인한다.

### 검수

재단·피드 크롭·자막·버튼을 얹어도 핵심 메시지가 가려지지 않는지 확인.

### 수정 명령

```text
‘중앙에 배치’ 대신 가려지는 영역을 수치 또는 오버레이로 제공하고 그 안으로 재배치하라.
```

<a name="d4-08"></a>
## D4-08 · 오버프린트·녹아웃

**Overprint / Knockout** · PDF 32쪽

### 뜻·쓰임

오버프린트는 아래 잉크를 남긴 채 위 잉크를 겹쳐 인쇄하고, 녹아웃은 위 요소 아래를 비우는 처리다. 겹치는 색·작은 검정 글자·분판을 제어할 때 쓴다.

### 혼동 구분

레이어 순서나 화면의 Multiply 효과와 동일하지 않다. 특히 흰색 오버프린트는 출력에서 사라지는 문제를 만들 수 있다.

### 실행 명령

```text
작은 검정 글자의 오버프린트 정책을 인쇄소와 확인하고 흰색 객체의 오버프린트는 제거하라. 분판 미리보기로 겹침을 검토하라.
```

### 설정·계약

검정 구성·별색·용지에 따라 정책이 다르다. 투명도 병합과 PDF 출력 후에도 설정이 유지되는지 확인한다.

### 검수

오버프린트 미리보기 전후에서 로고·흰 글자·색 겹침이 의도대로 보이는지 검사.

### 수정 명령

```text
화면 스크린샷만 승인하지 말고 실제 출력 PDF의 분판과 오버프린트 상태를 확인하라.
```

<a name="d4-09"></a>
## D4-09 · 래스터 해상도

**PPI / DPI** · PDF 33쪽

### 뜻·쓰임

PPI는 이미지의 인치당 픽셀 수, DPI는 출력 장치의 인치당 점 수를 뜻한다. 인쇄 이미지의 유효 해상도와 출력 장치 성능을 구분할 때 쓴다.

### 혼동 구분

메타데이터를 72에서 300으로 바꿔도 픽셀 수가 그대로면 디테일은 증가하지 않는다. 화면의 CSS px도 물리적 인치와 고정 대응하지 않는다.

### 실행 명령

```text
인쇄 배치 크기에서 사진의 유효 PPI를 계산하라. 3000px 폭 이미지를 10인치로 배치하면 300PPI임을 명시하고 부족한 원본을 표시하라.
```

### 설정·계약

필요 PPI는 시청 거리·인쇄 방식·이미지 종류에 따라 정한다. 업스케일은 보간·생성된 디테일을 추가할 수 있으나 원본 정보 복원 보장은 아니다.

### 검수

실제 배치 크기로 확대·출력해 윤곽과 글자, 압축 흔적을 확인.

### 수정 명령

```text
DPI 숫자만 높이지 말고 원본 픽셀 수·배치 크기·필요 품질의 관계를 다시 계산하라.
```

<a name="d4-10"></a>
## D4-10 · 소프트 프루프

**Soft Proof** · PDF 33쪽

### 뜻·쓰임

모니터에서 목표 인쇄 조건의 색을 시뮬레이션해 미리 확인하는 과정이다. 색역 차이·종이색·잉크 한계를 예상하고 교정 방향을 정할 때 쓴다.

### 혼동 구분

종이 교정쇄와 동일한 물리 결과를 보장하지 않는다. 모니터 보정·주변 조명·프로파일이 잘못되면 판단도 흔들린다.

### 실행 명령

```text
목표 인쇄 프로파일로 소프트 프루프를 적용하고 브랜드 색·회색·암부의 변화 목록을 작성하라. 중요한 색은 교정쇄 확인 대상으로 표시하라.
```

### 설정·계약

시뮬레이션 옵션과 렌더링 인텐트를 기록한다. 일반 화면 납품본을 프루프 화면 자체로 저장하지 않는다.

### 검수

프루프 켬/끔을 비교하고 암부 뭉침·색역 손실이 조정 후 완화되는지 확인.

### 수정 명령

```text
모니터에서 더 선명하게만 만들지 말고 목표 인쇄 조건에서 구별되는 색 관계를 확보하라.
```
