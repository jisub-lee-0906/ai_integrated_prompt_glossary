<a name="d8-01"></a>
## D8-01 · 토폴로지 (Topology)

**Topology** · PDF 53쪽

### 뜻·쓰임

정점·변·면의 연결 구조다. 변형·세분화·음영 품질에 영향을 주므로 게임·캐릭터·제품 모델을 납품할 때 확인한다.

### 혼동 구분

폴리곤 수가 적다고 좋은 토폴로지는 아니다. 정지 소품과 관절 변형 캐릭터는 필요한 구조가 다르다.

### 실행 명령

```text
캐릭터의 팔꿈치·무릎에 변형을 고려한 edge flow를 만들고 중복 정점·내부 면·비정상 연결을 점검하라.
```

### 설정·계약

예산·삼각형화 시점·변형 부위를 명시한다. quad만 고집하지 말고 엔진과 애니메이션 요구에 맞춘다.

### 검수

관절을 굽히고 subdivision을 적용해 찌그러짐·핀칭·음영 오류를 확인.

### 수정 명령

```text
면 수만 줄이지 말고 변형 축 주변의 루프와 밀도를 재구성하라.
```

<a name="d8-02"></a>
## D8-02 · 리토폴로지 (Retopology)

**Retopology** · PDF 53쪽

### 뜻·쓰임

스캔·조각·고밀도 메시 위에 목적에 맞는 연결 구조를 다시 만드는 과정이다. 실시간 렌더·리깅·편집 가능한 자산으로 전환할 때 쓴다.

### 혼동 구분

Decimation은 주로 면 수를 줄이는 처리이며 적절한 변형용 루프를 자동으로 보장하지 않는다.

### 실행 명령

```text
스캔한 의자를 게임용 메시로 리토폴로지하고 실루엣·접촉부 디테일을 우선 보존하라. 원본 대비 오차와 삼각형 수를 보고하라.
```

### 설정·계약

목표 장치·뷰 거리·재질 수를 정한다. 세부 표면은 normal map 베이킹으로 옮길지 결정한다.

### 검수

실루엣·좌석 구멍·다리 두께가 유지되고 UV·법선이 정상인지 확인.

### 수정 명령

```text
평평한 곳은 단순화하고 실루엣 변화가 큰 곳에 면을 배분하라.
```

<a name="d8-03"></a>
## D8-03 · UV 언래핑 (UV Unwrapping)

**UV Unwrapping** · PDF 54쪽

### 뜻·쓰임

3D 표면을 2D 텍스처 좌표로 펼치는 작업이다. 그림·재질 맵이 모델의 어느 면에 놓일지 결정한다.

### 혼동 구분

텍스처 이미지 해상도와 다른 개념이다. 동일 해상도라도 UV 면적 배분에 따라 부위별 선명도가 달라진다.

### 실행 명령

```text
포장 상자의 UV를 패널별로 펼치고 로고 면의 왜곡을 최소화하라. seam 위치와 겹침 허용 여부를 표시하라.
```

### 설정·계약

체커 패턴으로 늘어남을 검사한다. 타일 경계·패딩·회전·공유 UV 여부를 목표 렌더러에 맞춘다.

### 검수

체커 크기가 고르고 글자·라벨이 이음매에서 깨지지 않는지 확인.

### 수정 명령

```text
텍스처만 키우지 말고 왜곡된 UV와 면적 배분을 먼저 수정하라.
```

<a name="d8-04"></a>
## D8-04 · 텍셀 밀도 (Texel Density)

**Texel Density** · PDF 54쪽

### 뜻·쓰임

모델의 실제 길이당 텍스처 픽셀 수를 나타내는 비율이다. 여러 자산의 표면 선명도를 일관되게 맞추는 데 쓴다.

### 혼동 구분

텍스처 파일 크기만으로 정해지지 않는다. 모델 스케일·UV 점유율·관찰 거리가 함께 작용한다.

### 실행 명령

```text
환경 소품의 텍셀 밀도를 동일 기준으로 맞추고 근접 촬영되는 표지판만 예외로 높은 밀도를 배정하라.
```

### 설정·계약

예: 512px/m는 프로젝트 시험값이다. 장면 단위와 스케일을 확정하고 재질별 예외를 기록한다.

### 검수

같은 거리에서 나무·금속·라벨의 선명도가 의도치 않게 달라지지 않는지 확인.

### 수정 명령

```text
모든 텍스처를 4K로 만들기보다 UV·거리·메모리 예산에 맞춰 배분하라.
```

<a name="d8-05"></a>
## D8-05 · 물리 기반 렌더링 (Physically Based Rendering (PBR))

**Physically Based Rendering (PBR)** · PDF 55쪽

### 뜻·쓰임

빛과 재질의 상호작용을 물리적으로 그럴듯하게 계산하는 렌더링 접근이다. 많이 쓰는 metallic/roughness 워크플로에서는 기본색, 금속성, 거칠기 등이 재질을 결정한다. PBR이라는 단어만으로 실측 재질이 보장되지는 않는다.

### 혼동 구분

PBR은 특정 금속/거칠기 수치 하나가 아니라 빛·재질의 일관된 처리다. 엔진별 입력 계약을 확인한다.

### 실행 명령

```text
PBR render of a brushed metal kettle, physically plausible roughness, neutral studio illumination, realistic reflections and accurate scale.
```

### 설정·계약

금속/거칠기 방식의 순수 금속은 metallic 1, 비금속은 0이 전형적이다. roughness 0.2~0.5는 비교용 시작값이며 표면에 맞게 조정한다. 조명·노출을 고정한 뒤 재질을 비교한다.

### 검수

반사 속 주변 환경, 재질의 에너지감, 접지 그림자와 실제 물체 크기를 함께 확인.

### 수정 명령

```text
원본 색에 그림자가 구워져 있다면 base color와 음영 정보를 분리하라.
```

<a name="d8-06"></a>
## D8-06 · 노멀 맵 (Normal Map)

**Normal Map** · PDF 55쪽

### 뜻·쓰임

표면 법선 방향을 바꿔 작은 요철의 조명 효과를 만드는 맵이다. 기하를 크게 늘리지 않고 세부를 표현할 때 쓰인다.

### 혼동 구분

Displacement와 달리 일반적인 normal map은 실루엣을 바꾸지 않는다. tangent-space의 축 관례가 다르면 요철이 뒤집혀 보일 수 있다.

### 실행 명령

```text
고해상도 메시의 디테일을 tangent-space normal map으로 베이크하고 목표 엔진의 Y 채널 관례에 맞춰라.
```

### 설정·계약

색 데이터가 아닌 맵으로 해석하도록 설정하고 UV·탠전트·삼각형화 조건을 맞춘다.

### 검수

광원을 돌려 볼록·오목 방향과 seam·경계 음영을 검사.

### 수정 명령

```text
강도만 높이지 말고 채널 방향·맵 색공간·탠전트 불일치를 먼저 점검하라.
```

**함께 구분할 용어:** [디스플레이스먼트 / Displacement](D8.md#d8-07)

## D8-07 · 디스플레이스먼트 (Displacement)

**Displacement** · PDF 56쪽

### 뜻·쓰임

높이 또는 벡터 정보로 실제 표면 위치를 이동시키는 처리다. 실루엣·접촉 그림자까지 변해야 하는 요철에 유용하다.

### 혼동 구분

Bump·Normal은 주로 음영을 바꾸며 실제 기하 변화와 다르다. 렌더러 설정에 따라 진짜 변위 사용 여부가 달라진다.

### 실행 명령

```text
벽돌 표면의 큰 높낮이는 displacement, 작은 거칠기는 normal로 분리하고 장면 단위에 맞는 변위 크기를 지정하라.
```

### 설정·계약

기준 높이·스케일·세분화 수준·메모리 비용을 명시한다. 맵을 비색 데이터로 해석한다.

### 검수

실루엣 변화·틈·과도한 부풀음·렌더 시간 증가를 확인.

### 수정 명령

```text
요철을 더 강하게만 하지 말고 기준점과 실제 높이 단위를 맞춰라.
```

**함께 구분할 용어:** [노멀 맵 / Normal Map](D8.md#d8-06)

## D8-08 · 베이킹 (Baking)

**Baking** · PDF 56쪽

### 뜻·쓰임

복잡한 계산·고밀도 모델의 결과를 텍스처나 캐시로 저장하는 과정이다. 실시간 성능 확보와 재현 가능한 납품에 쓰인다.

### 혼동 구분

최종 이미지 렌더와 다르다. 어떤 정보를 어느 맵에 저장했는지 명확해야 중복 음영을 피할 수 있다.

### 실행 명령

```text
high-poly에서 low-poly로 normal·AO를 분리 베이크하고 cage·ray distance·패딩을 기록하라. base color에는 조명을 섞지 마라.
```

### 설정·계약

UV 중복·투사 오류·맵 규격을 확인한다. 타깃 엔진과 일치하는 법선 조건에서 베이크한다.

### 검수

가까운 면의 정보가 잘못 찍히거나 UV seam에 검은 선이 생기지 않는지 확인.

### 수정 명령

```text
맵을 흐리게 덮지 말고 cage와 광선 투사 범위를 수정해 다시 베이크하라.
```

## D8-09 · 앰비언트 오클루전 (Ambient Occlusion (AO))

**Ambient Occlusion (AO)** · PDF 57쪽

### 뜻·쓰임

틈이나 접촉부처럼 주변광이 덜 들어오는 영역을 어둡게 표현하는 근사 기법이다. 작은 구조의 깊이를 읽기 쉽게 하지만 실제 광원 그림자나 모든 간접광 계산을 대체하지는 않는다.

### 혼동 구분

AO는 차폐에 따른 간접광 감소의 근사다. 주 광원의 그림자와 동일하지 않으며 중복 적용에 주의한다.

### 실행 명령

```text
Use subtle ambient occlusion at contact points and creases, soft indirect lighting and clean shadows without dirty dark halos.
```

### 설정·계약

AO 반경은 장면 단위와 물체 크기에 맞춘다. 과도한 강도는 벽 모서리와 얼굴을 더럽게 보이게 한다. 이미 간접 조명이 반영된 렌더에는 중복 적용을 줄여 비교한다.

### 검수

밝은 재질이 회색으로 뭉개지지 않고, 떨어진 물체 사이에 검은 후광이 생기지 않는지 확인.

### 수정 명령

```text
모서리가 더럽게 보이면 AO 강도·반경을 줄이고 기존 간접광과 중복되는지 확인하라.
```

## D8-10 · 리깅·스키닝 (Rigging / Skinning)

**Rigging / Skinning** · PDF 57쪽

### 뜻·쓰임

리깅은 조작용 뼈·컨트롤·제약을 만들고 스키닝은 메시가 그 구조를 따라 변형되는 가중치를 정하는 작업이다. 캐릭터 애니메이션 납품의 핵심이다.

### 혼동 구분

움직이는 영상만으로 편집 가능한 리그가 있는 것은 아니다. 관절 위치와 가중치 문제는 구별해 수정한다.

### 실행 명령

```text
캐릭터에 명명된 뼈 계층과 기본 컨트롤을 만들고 어깨·팔꿈치·무릎 가중치를 조정하라. 기본 포즈와 관절 테스트 포즈를 제공하라.
```

### 설정·계약

축 방향·단위·바인드 포즈·엔진 제한·뼈 수를 합의한다. IK/FK는 필요한 동작에 맞춰 설계한다.

### 검수

극단 포즈에서 찢어짐·부피 손실·관절 뒤집힘을 확인.

### 수정 명령

```text
애니메이션으로 오류를 숨기지 말고 관절 위치·가중치·보정 변형을 구분해 수정하라.
```
