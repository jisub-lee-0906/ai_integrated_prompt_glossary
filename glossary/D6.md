<a name="d6-01"></a>
## D6-01 · 클레이 애니메이션풍 (Claymation)

**Claymation** · PDF 41쪽

### 뜻·쓰임

점토 인형을 조금씩 움직여 촬영하는 스톱모션 기법 또는 그 시각적 스타일이다. 정지 이미지에서는 점토 표면과 손으로 만든 흔적을 요청하는 말로 쓰며, 단순히 매끈한 3D 렌더와는 질감이 다르다.

### 혼동 구분

Claymation은 점토 기반 스톱모션 또는 그 스타일이다. 매끈한 플라스틱 3D와 촉감이 다르다.

### 실행 명령

```text
Claymation-style friendly robot, hand-sculpted clay texture, subtle fingerprints, rounded shapes, tactile matte finish.
```

### 설정·계약

matte clay, small surface imperfections로 재질을 구체화한다. 영상에서는 ‘포즈를 2프레임씩 유지’처럼 동작 간격을 지정할 수 있으나 실제 타이밍은 편집에서 확인한다. Plastic, glossy와 무심코 섞지 않는다.

### 검수

관절·얼굴 형태가 유지되고, 점토 질감이 피부 잡티처럼 과장되지 않는지 확인.

### 수정 명령

```text
광택을 줄이고 작은 손자국·불균일한 표면을 더하되 형상과 얼굴은 안정적으로 유지하라.
```

<a name="d6-02"></a>
## D6-02 · 글래스모피즘 (Glassmorphism)

**Glassmorphism** · PDF 41쪽

### 뜻·쓰임

반투명 레이어, 배경 흐림, 얇은 테두리로 유리판의 깊이를 표현하는 UI 스타일이다. 카드 전체 opacity를 낮추면 글자까지 흐려지므로, 실제 구현에서는 배경의 알파와 배경 필터를 분리하는 편이 낫다.

### 혼동 구분

글래스모피즘은 배경·투명도·흐림의 조합이다. 카드 전체 opacity를 낮춰 글자까지 흐리게 하지 않는다.

### 실행 명령

```text
Design a dashboard with frosted glass cards, subtle background blur, translucent borders, readable dark labels and restrained sky-blue accents.
```

### 설정·계약

시작값 예: 흰 배경 alpha 0.75, backdrop-filter blur(12px), 1px border. 모두 구현 예시이지 AI 공통 파라미터는 아니다. 복잡한 배경과 저성능 환경에는 불투명 대체 스타일을 둔다.

### 검수

가장 밝고 어두운 배경 모두에서 텍스트 대비를 검사하고, 흐림 미지원 상황을 확인.

### 수정 명령

```text
유리 효과가 본문을 방해하면 배경 알파를 높이고 글자 레이어는 불투명하게 유지하라.
```

<a name="d6-03"></a>
## D6-03 · 포토리얼리즘 (Photorealism)

**Photorealism** · PDF 42쪽

### 뜻·쓰임

실제 사진처럼 빛·재질·렌즈·구조가 그럴듯하게 보이는 표현 목표다. 제품 광고와 건축 시각화에 쓰며 ‘고해상도’와 동일하지 않다.

### 혼동 구분

세부 무늬가 많아도 물리 관계가 틀리면 사실적이지 않다. 사실 같은 이미지는 실제 촬영의 증거가 아니다.

### 실행 명령

```text
Photorealistic product photography: 실제 크기의 세라믹 컵, 일관된 창문 반사, 바닥 접지, 자연스러운 미세 표면과 제한된 심도를 표현하라.
```

### 설정·계약

광원 크기·방향·재질·카메라 높이를 먼저 정한다. 과한 샤프닝·미세 질감·HDR 효과를 사실감으로 대체하지 않는다.

### 검수

반사 속 환경·그림자 방향·손잡이 구조·초점의 일관성을 확인.

### 수정 명령

```text
‘더 리얼하게’ 대신 잘못된 반사와 접촉 그림자를 지정해 수정하라.
```

<a name="d6-04"></a>
## D6-04 · 셀 셰이딩 (Cel Shading)

**Cel Shading** · PDF 42쪽

### 뜻·쓰임

연속 음영을 제한된 명암 단계와 윤곽으로 단순화하는 렌더링 스타일이다. 애니메이션·게임풍 이미지를 명확한 면으로 표현할 때 쓴다.

### 혼동 구분

단순 저폴리와 다르다. 모델은 곡면이어도 음영을 단계화할 수 있고 외곽선은 별도 처리일 수 있다.

### 실행 명령

```text
Cel-shaded robot with two shadow bands, clean contour lines, stable face proportions and a single key light. 금속 사진 질감은 줄여라.
```

### 설정·계약

명암 단계 수·윤곽선 두께·그림자 색·광원 방향을 지정한다. 단계 경계가 얼굴 구조를 깨지 않게 한다.

### 검수

면별 명암 경계와 외곽선이 프레임마다 흔들리지 않는지 확인.

### 수정 명령

```text
흐릿한 그라데이션을 제한된 명암 면으로 바꾸되 실루엣은 유지하라.
```

<a name="d6-05"></a>
## D6-05 · 로우 폴리 스타일 (Low-poly Style)

**Low-poly Style** · PDF 43쪽

### 뜻·쓰임

적은 면과 드러나는 다각형 구조를 시각 특징으로 사용하는 스타일이다. 미니어처 풍경·게임 자산 콘셉트에 쓰인다.

### 혼동 구분

실제 최적화된 메시라는 보장은 아니다. 렌더 이미지의 삼각형 느낌과 파일의 폴리곤 수는 별도다.

### 실행 명령

```text
Low-poly mountain scene with broad planar faces and restrained colors. 실제 3D 납품에는 삼각형 수·재질 수·텍스처 규격을 보고하라.
```

### 설정·계약

얼굴·실루엣에 필요한 면은 남긴다. 게임용 예산은 목표 장치와 씬 규모에 맞춰 합의한다.

### 검수

이미지의 면 구조가 일관적이고 실제 모델 통계가 예산을 만족하는지 확인.

### 수정 명령

```text
표면에 삼각형 무늬만 그리지 말고 필요한 경우 기하 자체를 단순화하라.
```

<a name="d6-06"></a>
## D6-06 · 키·필·림 라이트 (Key / Fill / Rim Light)

**Key / Fill / Rim Light** · PDF 43쪽

### 뜻·쓰임

키는 주된 형태를 만드는 광원, 필은 그림자 대비를 조절하는 보조광, 림은 외곽 분리를 돕는 역광이다. 제품·인물의 입체감과 배경 분리를 지시할 때 쓴다.

### 혼동 구분

세 광원이 반드시 필요한 규칙은 아니다. 각 광원의 역할이 겹치면 평평하거나 방향 없는 조명이 된다.

### 실행 명령

```text
카메라 왼쪽 위에 넓은 key, 오른쪽 약한 fill, 뒤쪽 얇은 rim을 두고 얼굴과 제품의 반사 방향을 일치시켜라.
```

### 설정·계약

위치·상대 밝기·크기·색을 적는다. 스톱 차이와 광량 비율은 측정 조건을 함께 명시한다.

### 검수

그림자가 여러 방향으로 모순되지 않고 림이 오려 붙인 후광처럼 보이지 않는지 확인.

### 수정 명령

```text
전체를 밝히기보다 필 강도만 줄이거나 늘려 원하는 대비를 맞춰라.
```

## D6-07 · 하드·소프트 라이트 (Hard / Soft Light)

**Hard / Soft Light** · PDF 44쪽

### 뜻·쓰임

빛의 경계가 날카로운지 부드러운지를 설명하는 말이다. 피사체에서 본 광원의 상대 크기가 그림자의 부드러움에 큰 영향을 준다.

### 혼동 구분

밝고 어두움이나 색온도와 다른 특성이다. 작은 광원이 강하다고 소프트해지는 것은 아니다.

### 실행 명령

```text
Soft light from a large window close to the subject, gradual shadow transitions and a readable contact shadow. 배경 밝기는 별도로 유지하라.
```

### 설정·계약

광원 크기와 거리를 함께 조절한다. 큰 면광원도 아주 멀면 상대 크기가 작아져 결과가 달라진다.

### 검수

턱·손잡이·바닥 그림자의 경계가 같은 광원 조건에 부합하는지 확인.

### 수정 명령

```text
노출을 올려 그림자를 지우지 말고 광원의 상대 크기를 늘려 부드럽게 하라.
```

<a name="d6-08"></a>
## D6-08 · 색온도·화이트밸런스 (Color Temperature / White Balance)

**Color Temperature / White Balance** · PDF 44쪽

### 뜻·쓰임

색온도는 광원의 색 경향을, 화이트밸런스는 그 조명 아래 중성색을 어떻게 해석할지 나타낸다. 장면의 따뜻함과 샷 간 색 일치를 지시할 때 쓰인다.

### 혼동 구분

화이트밸런스 슬라이더의 숫자는 광원 자체를 바꾸는 값과 구별한다. 녹색·자홍 편향은 tint로 따로 조절하는 경우가 많다.

### 실행 명령

```text
따뜻한 실내 광원은 유지하되 제품의 흰 라벨은 중성에 가깝게 보정하라. 혼합광의 영역별 색 차이를 자연스럽게 남겨라.
```

### 설정·계약

3200K·5600K는 익숙한 예시일 뿐 모든 광원 특성을 설명하지 않는다. 기준 회색과 소스 촬영 조건을 함께 확인한다.

### 검수

흰색·피부·금속의 색 틀어짐과 샷 사이 온도 변화가 의도적인지 확인.

### 수정 명령

```text
이미지 전체에 주황 필터를 씌우지 말고 광원색과 중성 기준을 분리해 조절하라.
```

<a name="d6-09"></a>
## D6-09 · 로우 키·하이 키 (Low-key / High-key Lighting)

**Low-key / High-key Lighting** · PDF 45쪽

### 뜻·쓰임

어두운 톤과 강한 대비 또는 밝은 톤과 낮은 대비를 중심으로 장면을 구성하는 조명·톤 전략이다. 무게감·청량감 같은 인상을 구체화한다.

### 혼동 구분

단순 노출 부족·과다와 다르다. low-key에서도 필요한 암부 정보가, high-key에서도 밝은 물체 경계가 남아야 한다.

### 실행 명령

```text
High-key skincare still life with soft bright backgrounds, preserved white packaging edges and controlled specular highlights.
```

### 설정·계약

배경·피사체·그림자 밝기의 관계를 정한다. 히스토그램과 실제 재질 경계를 함께 보고 클리핑을 제한한다.

### 검수

흰 물체가 배경에서 사라지거나 검은 제품의 형태가 막히지 않는지 확인.

### 수정 명령

```text
밝기만 일괄 올리지 말고 배경과 피사체 분리를 유지하면서 전체 톤을 조정하라.
```

<a name="d6-10"></a>
## D6-10 · 볼류메트릭 라이팅 (Volumetric Lighting)

**Volumetric Lighting** · PDF 45쪽

### 뜻·쓰임

안개·먼지 같은 매질 안에서 빛이 산란해 광선과 공간의 깊이가 보이는 표현이다. 무대·숲·산업 공간의 분위기를 만드는 데 쓰인다.

### 혼동 구분

화면 위에 흰 줄을 그은 효과와 다르며 실제 광원·매질·가림 관계가 필요하다.

### 실행 명령

```text
Volumetric sun rays entering through one high window, subtle airborne dust, coherent occlusion and readable foreground subjects.
```

### 설정·계약

매질 밀도·광원 방향·범위·노출을 정한다. 밀도가 높으면 대비와 주제 가독성이 떨어질 수 있다.

### 검수

광선이 벽을 통과하지 않고 물체 뒤 가림과 거리에 따른 흐림이 일관적인지 확인.

### 수정 명령

```text
안개를 전면에 동일하게 덮지 말고 거리·빛 경로에 따른 밀도를 표현하라.
```
