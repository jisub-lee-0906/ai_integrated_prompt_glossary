<a name="d5-01"></a>
## D5-01 · 플랫 벡터 스타일 (Vector Flat)

**Vector Flat** · PDF 35쪽

### 뜻·쓰임

단색 면과 단순한 경계로 구성하는 시각 양식이다. ‘vector’라는 프롬프트만으로 생성 이미지가 편집 가능한 벡터 파일이 되지는 않는다. 실제 벡터는 경로·도형을 가진 SVG 같은 형식으로 납품해야 한다.

### 혼동 구분

Vector Flat은 시각 스타일이고 실제 벡터는 경로 데이터다. SVG 확장자 안에 래스터 이미지만 들어 있을 수도 있다.

### 실행 명령

```text
Flat vector-style illustration of a delivery bicycle, solid color fills, clean closed shapes, consistent outlines, limited four-color palette.
```

### 설정·계약

스타일 요청에는 no gradients처럼 면 처리를 명확히 쓴다. 실제 SVG가 필요하면 코드 생성 도구에 viewBox, path, fill, stroke 및 외부 래스터 미포함 조건을 추가하고 파일을 렌더링한다.

### 검수

확대 시 선명도뿐 아니라 SVG 내부에 경로가 있는지 확인. PNG를 SVG로 감싼 결과는 제외.

### 수정 명령

```text
SVG 내부의 image 태그를 확인하고 실제 편집 가능한 도형·경로로 재구성하라.
```

**함께 구분할 용어:** [베지어 경로 / Bézier Path](D5.md#d5-02)

<a name="d5-02"></a>
## D5-02 · 베지어 경로 (Bézier Path)

**Bézier Path** · PDF 35쪽

### 뜻·쓰임

앵커와 제어 핸들로 직선·곡선을 구성하는 벡터 표현이다. 로고·아이콘·모션 경로를 정밀하게 편집할 때 쓰며 점 수보다 곡률의 연속성이 중요하다.

### 혼동 구분

래스터의 픽셀 윤곽과 다르다. 자동 추적에서 생긴 과도한 앵커는 확대 시 울퉁불퉁함과 편집 어려움을 만든다.

### 실행 명령

```text
잎 아이콘을 닫힌 베지어 경로로 만들고 매끄러운 부분의 접선 방향을 연결하라. 불필요한 앵커를 줄이며 실루엣을 유지하라.
```

### 설정·계약

모서리는 corner, 곡선은 smooth로 구분한다. SVG viewBox와 좌표 단위를 명시하고 경로의 시작·끝이 의도대로 닫혔는지 확인한다.

### 검수

큰 확대와 실제 아이콘 크기에서 꺾임·자가 교차·원치 않는 구멍을 확인.

### 수정 명령

```text
앵커를 무작정 추가하지 말고 핸들의 길이와 방향을 정리하라.
```

**함께 구분할 용어:** [플랫 벡터 스타일 / Vector Flat](D5.md#d5-01)

<a name="d5-03"></a>
## D5-03 · 선과 면 (Stroke / Fill)

**Stroke / Fill** · PDF 36쪽

### 뜻·쓰임

벡터 도형의 윤곽선과 내부 색 영역이다. 아이콘 세트의 두께·끝 모양·모서리 인상을 통일할 때 쓰이며 선은 도형 크기와 함께 확대될지 정책을 정해야 한다.

### 혼동 구분

선 두께를 키우는 것과 도형 외곽을 확장하는 것은 결과가 다르다. SVG 선 정렬 지원은 도구마다 다를 수 있다.

### 실행 명령

```text
24×24 viewBox 아이콘에 1.5 단위 stroke, round cap·join, fill none을 적용하고 아이콘마다 광학적 중심을 맞춰라.
```

### 설정·계약

숫자는 좌표계 기준이다. 외곽선 확장이 필요한 납품이면 편집 원본과 확장본을 구분한다.

### 검수

작은 크기에서 선이 끊기거나 둔탁하지 않고 끝·모서리가 일관적인지 확인.

### 수정 명령

```text
아이콘마다 임의 두께를 쓰지 말고 공통 stroke 규칙과 광학적 예외를 명시하라.
```

<a name="d5-04"></a>
## D5-04 · 불리언 연산 (Boolean Operations)

**Boolean Operations** · PDF 36쪽

### 뜻·쓰임

도형의 합집합·차집합·교집합 등을 이용해 새로운 형태를 만드는 작업이다. 로고의 음각 구멍이나 결합 아이콘을 편집 가능한 구조로 만들 때 쓴다.

### 혼동 구분

시각적으로 겹친 두 도형이 하나의 경로가 된 것은 아니다. compound path의 구멍 규칙과 구별한다.

### 실행 명령

```text
원과 사각형을 Unite로 결합하고 내부 원은 Subtract로 뚫어라. 납품 SVG에는 중복 겹침과 불필요한 내부 경계를 제거하라.
```

### 설정·계약

연산 순서와 원본 보존 여부를 정한다. 복잡한 경로는 fill-rule에 따라 내부가 달라질 수 있다.

### 검수

반전 배경·외곽선 보기에서 구멍이 실제로 뚫리고 자가 교차가 없는지 확인.

### 수정 명령

```text
배경색 도형을 얹어 구멍처럼 보이게 하지 말고 실제 차집합 구조로 수정하라.
```

<a name="d5-05"></a>
## D5-05 · 클리핑 마스크 (Clipping Mask)

**Clipping Mask** · PDF 37쪽

### 뜻·쓰임

위 또는 기준 도형의 경계 안에서 다른 내용이 보이도록 제한하는 방식이다. 사진을 카드 모양으로 잘라 보이게 하면서 원본을 유지할 때 쓴다.

### 혼동 구분

삭제·크롭과 달리 숨은 내용이 남을 수 있다. 알파 마스크는 반투명 값을 표현할 수 있어 단순 경로 클리핑과 다르다.

### 실행 명령

```text
제품 사진을 라운드 카드 경로로 클리핑하고 원본 위치·크기를 편집 가능하게 유지하라. 경계 바깥 픽셀을 파괴적으로 삭제하지 마라.
```

### 설정·계약

대상과 마스크의 좌표계, 반전 여부, 비율 유지와 넘침 정책을 정한다.

### 검수

모서리 누출·얇은 테두리·이미지 늘어남이 없는지 확대 검사.

### 수정 명령

```text
흰 도형으로 가장자리를 가리지 말고 실제 마스크를 적용하라.
```

<a name="d5-06"></a>
## D5-06 · 블렌드 모드 (Blend Mode)

**Blend Mode** · PDF 37쪽

### 뜻·쓰임

위 레이어와 아래 레이어 색을 계산 규칙으로 결합하는 방식이다. Multiply·Screen·Overlay 등으로 음영·빛·질감을 합성한다.

### 혼동 구분

레이어 opacity나 인쇄 overprint와 다르다. 같은 모드도 색공간과 선형 처리 여부에 따라 외관이 달라질 수 있다.

### 실행 명령

```text
종이 질감은 Multiply로 시험하되 글자 가독성을 유지하고, 빛 반사는 Screen으로 합성한 전후를 비교하라.
```

### 설정·계약

모드·불투명도·작업 색공간을 기록한다. 흰색이 중립인 Multiply, 검정이 중립인 Screen의 동작을 활용한다.

### 검수

회색 배경·밝은 배경 모두에서 색이 탁해지거나 하이라이트가 날아가지 않는지 확인.

### 수정 명령

```text
모드만 바꿔 문제를 덮지 말고 소스의 검정·흰점과 알파를 함께 정리하라.
```

<a name="d5-07"></a>
## D5-07 · 알파 채널 (Alpha Channel)

**Alpha Channel** · PDF 38쪽

### 뜻·쓰임

RGB 색 정보와 별도로 픽셀의 불투명도를 저장하는 채널이다. ‘투명한 배경처럼 보임’과 실제 알파 데이터는 다르다. 일반적인 8비트 알파에서 0은 완전 투명, 255는 완전 불투명이다.

### 혼동 구분

알파는 파일 데이터다. 체크무늬가 그려진 배경은 알파가 아니며 흰색 배경도 투명하지 않다.

### 실행 명령

```text
Create an isolated product cutout; deliver a PNG with a real alpha channel, clean semi-transparent edges and no baked-in checkerboard.
```

### 설정·계약

지원하지 않는 생성기는 배경 제거 후 RGBA PNG로 내보낸다. 흰 배경이나 체크무늬는 투명 데이터가 아니다. 합성에서는 straight와 premultiplied alpha의 해석을 맞춰 가장자리 테두리를 방지한다.

### 검수

어두운 배경과 밝은 배경 위에 합성해 흰 테두리·검은 테두리·빠진 반투명 부분을 확인.

### 수정 명령

```text
밝고 어두운 배경 위에 합성했을 때 생기는 후광을 확인하고 알파 해석을 맞춰라.
```

**함께 구분할 용어:** [프리멀티플라이드 알파 / Premultiplied / Straight Alpha](V4.md#v4-04)

<a name="d5-08"></a>
## D5-08 · 이음매 없는 패턴 (Seamless Pattern)

**Seamless Pattern** · PDF 38쪽

### 뜻·쓰임

타일을 가로·세로로 반복했을 때 경계가 드러나지 않는 패턴이다. 패브릭, 배경, 텍스처에 쓰며 단순히 요소를 여러 번 그리는 ‘반복 무늬’와 구별된다. 상하·좌우 경계가 서로 이어져야 한다.

### 혼동 구분

무늬가 반복되는 것과 경계가 이어지는 것은 다르다. 이음매 없는 타일도 반복 덩어리가 눈에 띌 수 있다.

### 실행 명령

```text
Seamless repeating botanical pattern, evenly spaced leaves, balanced density, matching edges, flat colors, square tile.
```

### 설정·계약

정사각형은 관리가 쉬운 선택이지만 필수는 아니다. 도구가 제공하는 타일 기능은 별도 설정한다. 경계뿐 아니라 특정 잎·색 덩어리가 격자처럼 드러나는 저주파 반복도 줄인다.

### 검수

최소 3×3 타일로 이어 붙여 100%와 축소 화면에서 선·밝기·모티프 반복을 검사.

### 수정 명령

```text
3×3 미리보기에서 경계선과 밝기 띠를 고치고 큰 모티프의 격자 반복도 분산하라.
```

<a name="d5-09"></a>
## D5-09 · 안티앨리어싱 (Anti-aliasing)

**Anti-aliasing** · PDF 39쪽

### 뜻·쓰임

픽셀 격자로 경계를 표현할 때 생기는 계단 현상을 완화하는 처리다. 작은 아이콘·텍스트·대각선 그래픽의 화면 품질에 영향을 준다.

### 혼동 구분

흐림 필터로 전체를 번지게 만드는 것과 다르다. 픽셀아트는 의도적으로 선명한 격자를 유지할 수 있다.

### 실행 명령

```text
24px 아이콘을 실제 크기로 렌더링하고 대각선과 곡선의 계단을 완화하되 선 두께가 흐려지지 않게 조정하라.
```

### 설정·계약

좌표의 픽셀 정렬·렌더러·출력 배율을 함께 검사한다. 픽셀아트 확대는 nearest-neighbor 사용 여부를 명시한다.

### 검수

100% 배율에서 선의 진하기가 좌우 대칭이고 불필요한 회색 후광이 없는지 확인.

### 수정 명령

```text
확대 화면만 보지 말고 최종 크기의 렌더에서 경계를 조정하라.
```

<a name="d5-10"></a>
## D5-10 · 비파괴 편집 (Non-destructive Editing)

**Non-destructive Editing** · PDF 39쪽

### 뜻·쓰임

원본을 보존하면서 조정 레이어·마스크·스마트 객체 등으로 수정하는 방식이다. 반복 수정과 여러 납품 버전 관리에 유리하다.

### 혼동 구분

수정 이력만 남기는 것과 다르며, 레이어가 많아도 병합된 원본을 되돌릴 수 없으면 비파괴성이 제한된다.

### 실행 명령

```text
원본 사진은 보존하고 색보정·마스크·텍스트를 분리하라. 레이어 이름을 역할별로 정하고 편집 원본과 최종 평면화 파일을 함께 구분하라.
```

### 설정·계약

외부 링크 자산과 폰트의 의존성을 기록한다. 효과를 끄거나 마스크를 수정할 수 있는지 확인한다.

### 검수

원본 디테일·크롭 범위를 되돌리고 다른 배경에 재합성할 수 있는지 검사.

### 수정 명령

```text
완성 PNG만 수정하지 말고 원본 레이어에서 변경하고 납품본을 다시 내보내라.
```
