> 무엇을 분리하고 어떤 좌표·빛·색에 맞춰 합칠 것인가?

합성은 대상 분리만으로 끝나지 않는다. 추적·가림·좌표·초점·그레인·알파·색을 함께 맞춰야 한다. 후광·블러를 추가해 구조 오류를 숨기기 전에 매트와 공간 정합을 먼저 해결한다.

**작업 순서:** 매트 → 추적 → 공간 정합 → 가장자리 → 재질·색 일치

<a name="v4-01"></a>
## V4-01 · 크로마 키 (Chroma Key)

**Chroma Key** · PDF 77쪽

### 뜻·쓰임

특정 색 범위를 기준으로 배경을 분리하는 합성 기법이다. 녹색 배경 생성만으로 키잉이 끝나지는 않는다. 머리카락, 반투명 재질, 모션 블러와 배경색 반사가 결과를 크게 좌우한다.

### 혼동 구분

크로마 키는 배경색 분리이고 알파 데이터 자체와는 다르다. 같은 색의 의상과 반사는 분리를 방해한다.

### 실행 명령

```text
Film-style presenter against an evenly lit green screen, clear separation from the background and minimal green spill; prepare for keying.
```

### 설정·계약

대상이 녹색이면 다른 키 색을 고른다. 고른 조명과 피사체·배경 분리를 요청하고, 후반에서 matte 정리와 despill을 적용한다. 가능하다면 실제 알파 출력이 더 적합한지 비교한다.

### 검수

머리카락·손가락·옷 가장자리를 밝고 어두운 합성 배경에서 확인하고 녹색 테두리를 제거.

### 수정 명령

```text
녹색 테두리를 줄이되 머리카락·반투명 가장자리를 함께 깎아내지 마라.
```

<a name="v4-02"></a>
## V4-02 · 로토스코핑 (Rotoscoping)

**Rotoscoping** · PDF 77쪽

### 뜻·쓰임

프레임을 따라 물체의 윤곽을 분리하고 마스크를 추적·수정하는 작업이다. 원래 의미의 실사 동작 추적 애니메이션과 관련되지만 VFX에서는 매트 제작 문맥이 흔하다. 움직이는 대상 분리에 사용한다.

### 혼동 구분

로토는 시간에 따른 마스크 제작·수정이다. 정지 이미지의 한 번 선택과 달리 가림 뒤 일관성이 중요하다.

### 실행 명령

```text
Create a temporally consistent roto matte for the dancer, preserving hair and motion-blurred edges through occlusions.
```

### 설정·계약

선명한 기준 프레임에서 시작해 앞뒤로 전파하고 가림·빠른 회전 구간을 수동 보정한다. matte feather를 지나치게 키우면 윤곽이 줄어들거나 후광이 생긴다. 머리카락과 본체는 분리 검토한다.

### 검수

시간축에서 마스크가 끓듯 흔들리는지, 가림 뒤 대상이 바뀌는지, 원래 블러가 보존되는지 확인.

### 수정 명령

```text
가림 구간의 기준 프레임을 다시 잡고 전후 전파 결과를 수동 검토하라.
```

<a name="v4-03"></a>
## V4-03 · 알파·루마 매트 (Alpha Matte / Luma Matte)

**Alpha Matte / Luma Matte** · PDF 78쪽

### 뜻·쓰임

다른 레이어의 불투명도 또는 밝기 정보를 가시 영역으로 사용하는 합성 방식이다. 타이틀 리빌·연기 전환·질감 마스크에 쓰인다.

### 혼동 구분

검정 RGB라도 알파가 불투명하면 alpha matte에서 보일 수 있다. Luma는 밝기 해석에 의존한다.

### 실행 명령

```text
잉크 번짐 영상의 밝기를 luma matte로 사용해 제목을 드러내고 반전 여부와 검정·흰색 기준을 명시하라.
```

### 설정·계약

소스 채널·inverted 여부·레벨·feather를 정한다. 밝기 맵을 알파처럼 사용할 때 중간 회색은 반투명이 될 수 있다.

### 검수

목표 영역의 투명도와 가장자리 그라데이션, 색 변화 시 매트 변화 여부를 확인.

### 수정 명령

```text
색만 검게 칠하지 말고 실제 사용할 채널이 알파인지 루마인지 먼저 맞춰라.
```

<a name="v4-04"></a>
## V4-04 · 프리멀티플라이드 알파 (Premultiplied / Straight Alpha)

**Premultiplied / Straight Alpha** · PDF 78쪽

### 뜻·쓰임

Straight는 RGB와 알파를 분리하고 premultiplied는 RGB에 알파가 곱해진 형태를 사용한다. 합성·렌더 간 교환에서 해석이 맞지 않으면 테두리가 생긴다.

### 혼동 구분

배경이 투명해 보인다는 사실만으로 방식을 알 수 없다. 특정 코덱이 항상 한 방식만 쓰는 것으로 가정하지 않는다.

### 실행 명령

```text
렌더 자산의 alpha interpretation을 확인하고 합성 프로젝트와 일치시켜라. 검정·흰 배경 위 가장자리를 비교하라.
```

### 설정·계약

내보내기·가져오기 설정과 matte color를 기록한다. 이미 곱해진 색에 알파를 다시 곱하지 않는다.

### 검수

반투명 모서리에 검정·흰 후광이나 밝기 손실이 없는지 확인.

### 수정 명령

```text
마스크를 줄여 숨기지 말고 straight/premultiplied 해석 오류부터 수정하라.
```

**함께 구분할 용어:** [알파 채널 / Alpha Channel](D5.md#d5-07)

## V4-05 · 포인트 트래킹 (Point Tracking)

**Point Tracking** · PDF 79쪽

### 뜻·쓰임

영상 속 특징점의 이동을 추정하는 작업이다. 위치·회전·스케일 변화를 따라 자막·그래픽을 붙이거나 안정화할 때 사용한다.

### 혼동 구분

물체의 전체 면 변형이나 3D 카메라 복원과 다르다. 점이 가려지면 오차가 누적될 수 있다.

### 실행 명령

```text
셔츠의 대비 높은 두 특징점을 추적해 이름표 위치·회전을 연결하고 가림 구간은 수동 보정하라.
```

### 설정·계약

특징점 수·검색 범위·채널·시작 프레임·오차 허용을 정한다. 그림자·반사점은 추적 대상이 바뀌기 쉽다.

### 검수

처음·중간·끝과 가림 뒤에서 그래픽이 미끄러지지 않는지 확인.

### 수정 명령

```text
흐린 윤곽을 계속 추적하지 말고 안정적인 텍스처 점으로 기준을 바꿔라.
```

<a name="v4-06"></a>
## V4-06 · 플래너 트래킹 (Planar Tracking)

**Planar Tracking** · PDF 79쪽

### 뜻·쓰임

하나의 평면 영역의 원근 변화까지 추정하는 방식이다. 간판·화면·책 표지 교체에 적합하며 네 모서리 변환으로 결과를 연결할 수 있다.

### 혼동 구분

비평면 얼굴·천의 복잡한 변형에 그대로 적용하면 한계가 있다. 3D camera tracking과 다르다.

### 실행 명령

```text
벽 포스터의 평면을 추적해 새 그래픽을 corner pin으로 삽입하고 앞을 지나는 인물은 별도 매트로 가려라.
```

### 설정·계약

평면의 충분한 텍스처·가림·모션 블러를 확인한다. 추적 영역과 실제 삽입 영역은 다를 수 있다.

### 검수

포스터 모서리와 질감이 카메라 이동에 따라 일관되게 붙어 있는지 확인.

### 수정 명령

```text
추적이 틀린 구간을 과한 블러로 숨기지 말고 기준 영역·프레임을 재설정하라.
```

<a name="v4-07"></a>
## V4-07 · 3D 카메라 트래킹 (3D Camera Tracking)

**3D Camera Tracking** · PDF 80쪽

### 뜻·쓰임

여러 특징점의 움직임을 이용해 카메라와 장면의 3D 관계를 추정하는 작업이다. 실사 위에 3D 물체를 배치할 때 쓰인다.

### 혼동 구분

카메라가 거의 회전만 하거나 시차가 부족하면 위치 복원이 불안정할 수 있다. 2D 안정화는 공간 복원이 아니다.

### 실행 명령

```text
실사 바닥의 특징을 추적해 카메라를 solve하고 원점·바닥 평면·장면 스케일을 설정한 뒤 3D 로고를 배치하라.
```

### 설정·계약

렌즈 왜곡·FPS·이동 물체 제외·트랙 품질을 점검한다. 실제 크기 기준물이 없으면 스케일은 상대적이다.

### 검수

물체의 접지·가림·시차가 여러 프레임에서 유지되고 미끄러짐이 없는지 확인.

### 수정 명령

```text
가상 물체 위치만 움직여 보정하지 말고 solve와 바닥 좌표부터 재검토하라.
```

<a name="v4-08"></a>
## V4-08 · 디스필 (Despill)

**Despill** · PDF 80쪽

### 뜻·쓰임

키 배경색이 피사체 가장자리·반사면에 묻은 색을 줄이는 처리다. 크로마 키 후 녹색·파란색 테두리를 정리할 때 쓰인다.

### 혼동 구분

마스크를 축소하는 것과 다르다. 의상의 실제 녹색까지 제거하면 색이 훼손된다.

### 실행 명령

```text
키잉 후 머리카락 주변의 녹색 spill을 제한적으로 줄이고 피부와 원래 녹색 소품은 보존하라.
```

### 설정·계약

대상 색 범위·강도·가장자리 제한·대체 색을 조절한다. 최종 배경과 함께 보며 색을 맞춘다.

### 검수

흰 머리카락·피부·반사 금속이 회색 또는 자홍색으로 바뀌지 않는지 확인.

### 수정 명령

```text
전체 녹색 채도를 없애지 말고 오염된 가장자리 영역에만 적용하라.
```

<a name="v4-09"></a>
## V4-09 · 클린 플레이트 (Clean Plate)

**Clean Plate** · PDF 81쪽

### 뜻·쓰임

제거할 대상이 없는 배경 영상·이미지 또는 복원한 배경이다. 물체 제거·와이어 제거·로토 합성에서 가려진 공간을 채우는 데 쓴다.

### 혼동 구분

원본의 다른 프레임을 쓰더라도 조명·원근·가림이 달라질 수 있다. 생성 복원 배경은 실제 기록과 구별한다.

### 실행 명령

```text
사람이 지나가기 전 배경으로 clean plate를 만들고 카메라 움직임에 맞춰 추적하라. 그림자와 반사 제거 범위도 지정하라.
```

### 설정·계약

참조 프레임·영역·시점·그레인·밝기를 맞춘다. 반복 무늬의 위상과 시간 변화도 확인한다.

### 검수

제거 영역이 끓거나 얼어붙어 보이지 않고 그림자·반사가 남지 않는지 확인.

### 수정 명령

```text
대상 몸체만 지우지 말고 연결된 그림자·반사·가림 변화를 함께 처리하라.
```

<a name="v4-10"></a>
## V4-10 · 라이트 랩 (Light Wrap)

**Light Wrap** · PDF 81쪽

### 뜻·쓰임

밝은 배경 빛이 전경 가장자리로 약하게 번지는 인상을 만드는 합성 기법이다. 전경과 배경의 분리감을 줄일 때 제한적으로 쓴다.

### 혼동 구분

모든 테두리에 동일한 후광을 만드는 효과가 아니다. 실제 광원 방향과 배경 밝기를 따라야 한다.

### 실행 명령

```text
창문 앞 인물의 밝은 배경 쪽 가장자리에만 약한 light wrap을 적용하고 얼굴 내부와 어두운 경계는 유지하라.
```

### 설정·계약

범위·강도·배경 샘플·마스크를 좁게 설정한다. 광학 블러·색 일치·알파 오류를 먼저 해결한다.

### 검수

전경이 지나치게 반투명하거나 하얗게 오려진 듯 보이지 않는지 확인.

### 수정 명령

```text
강한 wrap으로 키잉 오류를 덮지 말고 매트와 색 정합을 먼저 수정하라.
```
