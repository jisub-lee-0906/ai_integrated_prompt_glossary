<a name="v3-01"></a>
## V3-01 · 키프레임 (Keyframe)

**Keyframe** · PDF 71쪽

### 뜻·쓰임

시간축의 특정 순간에 속성 값을 지정한 기준점이다. 중간 상태는 보간 규칙으로 계산한다. 여기서의 애니메이션 키프레임은 압축 영상의 I-frame과 다른 개념이므로 문맥을 함께 적어야 한다.

### 혼동 구분

애니메이션 keyframe은 속성 기준점이고 압축의 keyframe/I-frame은 영상 부호화 문맥이다.

### 실행 명령

```text
Animate the title with keyframes: at 0s opacity 0 and y 16px; at 0.4s opacity 1 and y 0; hold until 2s.
```

### 설정·계약

초 또는 프레임 중 기준 단위를 통일한다. 위치·회전·스케일·불투명도에 각각 시작값과 끝값을 준다. 24fps에서 0.4초는 정수 프레임과 맞지 않으므로 실제 타임라인에서 반올림 방식을 정한다.

### 검수

시작·끝 상태와 중간 경로를 확인하고 예상치 못한 회전 방향이나 스케일 튐을 검사.

### 수정 명령

```text
시간 단위를 프레임으로 통일하고 각 속성의 시작·끝값을 명시하라.
```

<a name="v3-02"></a>
## V3-02 · 이징 (Easing)

**Easing** · PDF 71쪽

### 뜻·쓰임

시작과 끝 사이의 시간 진행을 변환해 속도 변화를 만드는 규칙이다. linear는 일정한 진행, ease-in은 점차 가속, ease-out은 점차 감속하는 경향을 만든다. 움직임의 거리와 지속 시간도 체감에 영향을 준다.

### 혼동 구분

Easing은 시간에 따른 진행 속도를 바꾼다. 경로의 모양이나 총 지속 시간을 대신하지 않는다.

### 실행 명령

```text
Use ease-out for a panel entrance, duration 240ms, cubic-bezier(0.16, 1, 0.3, 1), ending at the exact target position.
```

### 설정·계약

위 베지어와 240ms는 UI용 출발 예시다. CSS cubic-bezier의 두 x 값은 0~1 범위여야 하고 y는 바깥 값도 허용된다. 반복 루프는 경계의 속도 연결을 별도로 검토한다.

### 검수

목적지에서 튀거나 지나치지 않는지, 반복 및 reduced-motion 환경에서도 기능이 명확한지 확인.

### 수정 명령

```text
도착 때 과하게 튀면 오버슈트 없는 곡선으로 바꾸고 거리와 시간을 함께 조절하라.
```

<a name="v3-03"></a>
## V3-03 · 모션 블러 (Motion Blur)

**Motion Blur** · PDF 72쪽

### 뜻·쓰임

노출 시간 동안 이동한 물체나 카메라의 흔적이 퍼져 보이는 현상이다. 부드러운 동작 감각을 주지만 과하면 정보를 지운다. 단순 프레임 보간이나 초점 흐림과 다르다.

### 혼동 구분

Motion Blur는 노출 동안의 이동 흔적이다. 초점 흐림·압축 번짐·보간 잔상과 다르다.

### 실행 명령

```text
Natural motion blur on fast-moving hands, stable facial detail and a restrained cinematic shutter look.
```

### 설정·계약

실촬영의 180° 셔터는 노출시간 약 1/(2×FPS)에 해당해 24fps에서는 약 1/48초다. 이는 관습적 시작점이다. 생성 영상의 ‘180-degree shutter’는 외형 지시이며 실제 노출 메타데이터 보장이 아니다.

### 검수

얼굴·로고는 읽히는지, 물체 윤곽이 이중으로 분열하거나 정지 영역까지 번지지 않는지 확인.

### 수정 명령

```text
정지 배경의 흐림은 줄이고 빠른 이동 부분에만 일관된 블러를 적용하라.
```

<a name="v3-04"></a>
## V3-04 · 이음매 없는 루프 (Seamless Loop)

**Seamless Loop** · PDF 72쪽

### 뜻·쓰임

끝에서 처음으로 넘어갈 때 위치·형태·밝기·운동 속도의 불연속이 느껴지지 않는 반복 영상이다. 첫·끝 프레임이 비슷해도 속도가 끊기면 튀어 보인다. 피사체뿐 아니라 그림자와 입자도 주기성이 필요하다.

### 혼동 구분

루프는 시작·끝 위치뿐 아니라 속도·빛·입자의 연속성도 필요하다. 첫 프레임의 중복 추가는 멈칫함을 만들 수 있다.

### 실행 명령

```text
A seamless loop of a small floating object gently oscillating, locked camera, stable lighting and a repeating periodic motion.
```

### 설정·계약

예: 4초·24fps는 96프레임이다. 주기의 끝에 처음과 동일한 프레임을 중복 삽입하면 멈칫할 수 있어 루프 길이를 맞춘다. 크로스페이드는 이중상 여부를 확인하며 사용한다.

### 검수

최소 5회 연속 재생해 경계 프레임의 위치·속도·노출과 오디오 클릭을 점검.

### 수정 명령

```text
루프 경계 양쪽의 위치·속도를 비교하고 정지 중복 프레임을 제거하라.
```

## V3-05 · 앵커 포인트 (Anchor Point / Pivot)

**Anchor Point / Pivot** · PDF 73쪽

### 뜻·쓰임

회전·스케일 변환의 기준이 되는 점이다. 문이 경첩에서 열리거나 원이 중심에서 커지는 동작을 만드는 데 중요하다.

### 혼동 구분

화면의 position과 다르다. 앵커만 옮기면 기존 위치가 달라질 수 있어 보정이 필요하다.

### 실행 명령

```text
카드의 아래쪽 중앙을 pivot으로 두고 그 지점을 고정한 채 0.95에서 1.0으로 확대하라.
```

### 설정·계약

좌표가 레이어 기준인지 씬 기준인지 명시한다. 앵커 변경 전후의 시각적 위치 유지 여부를 정한다.

### 검수

고정해야 할 지점이 미끄러지지 않고 회전·확대 방향이 일관적인지 확인.

### 수정 명령

```text
키프레임을 덧붙이기 전에 회전 중심을 실제 경첩·중심에 맞춰라.
```

## V3-06 · 부모·자식 계층 (Parenting / Hierarchy)

**Parenting / Hierarchy** · PDF 73쪽

### 뜻·쓰임

한 객체의 변환이 다른 객체를 따라가도록 계층을 연결하는 방식이다. 그룹 이동·리그·UI 모션을 관리할 때 쓴다.

### 혼동 구분

레이어 순서와 다르다. 부모 변환의 중복 적용이나 스케일 상속으로 자식이 왜곡될 수 있다.

### 실행 명령

```text
세 아이콘을 null 컨트롤에 parent하고 그룹 이동은 부모에서, 각 아이콘의 등장 모션은 자식에서 제어하라.
```

### 설정·계약

로컬/월드 좌표·스케일·회전 상속과 분리 시 위치 보존을 정한다. 순환 계층은 만들지 않는다.

### 검수

부모 이동·회전 후에도 자식 간 간격과 의도한 독립 동작이 유지되는지 확인.

### 수정 명령

```text
모든 레이어의 동일 키프레임을 복제하지 말고 공통 이동을 부모에 모아라.
```

## V3-07 · 모션 패스 (Motion Path)

**Motion Path** · PDF 74쪽

### 뜻·쓰임

객체가 공간에서 따라가는 경로다. 시간 보간과 분리해 궤적·방향 전환·회전 정렬을 제어한다.

### 혼동 구분

Easing은 경로를 따라가는 속도이고 path는 경로 모양이다. 둘을 혼동하면 곡선 자체가 잘못 바뀐다.

### 실행 명령

```text
점 아이콘이 S자 베지어 경로를 2초 동안 따라가고 경로의 접선 방향으로 회전하도록 하라.
```

### 설정·계약

경로 좌표·핸들·auto-orient·일정 속도 여부를 정한다. 곡률 큰 구간의 속도 변화를 확인한다.

### 검수

방향이 갑자기 뒤집히거나 경로 끝에서 위치가 튀지 않는지 확인.

### 수정 명령

```text
‘더 부드럽게’ 대신 곡률 연속성과 속도 변화 중 고칠 축을 지정하라.
```

<a name="v3-08"></a>
## V3-08 · 오버슈트·세틀링 (Overshoot / Settling)

**Overshoot / Settling** · PDF 74쪽

### 뜻·쓰임

목표값을 잠시 지나쳤다가 되돌아와 안정되는 움직임이다. 탄성·무게감·경쾌한 UI 피드백을 표현한다.

### 혼동 구분

모든 ease-out이 오버슈트를 갖는 것은 아니다. Bounce처럼 바닥에 튀는 표현과도 다르다.

### 실행 명령

```text
아이콘 스케일을 0.8→1.06→1.0으로 변화시키고 총 360ms 안에 안정되게 하라. 위치는 고정하라.
```

### 설정·계약

초과량·감쇠·진동 횟수·종료 시간을 정한다. 텍스트와 반복 행동에는 과한 탄성을 줄인다.

### 검수

끝값이 정확하고 짧은 반복 입력에도 진동이 계속 쌓이지 않는지 확인.

### 수정 명령

```text
튀는 횟수를 늘리기보다 초과량과 안정 시간을 줄여 반응성을 확보하라.
```

## V3-09 · 예비 동작·후속 동작 (Anticipation / Follow-through)

**Anticipation / Follow-through** · PDF 75쪽

### 뜻·쓰임

주동작 전 반대 방향의 준비 움직임과 주동작 이후 남는 관성 움직임이다. 캐릭터·오브젝트에 힘과 질량의 인상을 준다.

### 혼동 구분

단순 지연이나 랜덤 흔들림과 다르다. 원인과 결과의 순서가 동작 의도를 전달해야 한다.

### 실행 명령

```text
공이 점프하기 전 3프레임 눌리고 착지 후 한 번만 작게 흔들리게 하라. 전체 실루엣과 바닥 접점을 유지하라.
```

### 설정·계약

준비·주동작·감쇠 구간을 나눠 길이를 정한다. 과장 정도는 재질과 톤에 맞춘다.

### 검수

힘이 실리는 방향과 착지 반응이 연결되고 원래 크기가 영구적으로 변하지 않는지 확인.

### 수정 명령

```text
장식 흔들림을 추가하지 말고 주동작의 방향과 관성에 연결된 후속 동작으로 바꿔라.
```

## V3-10 · 키네틱 타이포그래피 (Kinetic Typography)

**Kinetic Typography** · PDF 75쪽

### 뜻·쓰임

텍스트의 등장·위치·크기·리듬을 시간축에서 설계하는 모션 그래픽이다. 발화 강조·타이틀·광고 메시지에 쓰인다.

### 혼동 구분

글자가 움직인다고 읽기 좋은 것은 아니다. 생성 영상의 부정확한 글자 대신 편집 가능한 텍스트 레이어가 필요할 수 있다.

### 실행 명령

```text
핵심 문장을 의미 단위로 등장시키고 강조 단어만 크기 변화하라. 편집 가능한 한글 텍스트 레이어와 자막 파일을 별도로 유지하라.
```

### 설정·계약

읽을 시간·줄 수·안전 영역·폰트·이징을 정한다. 장식 이동과 정보 읽기 구간을 구별한다.

### 검수

일시정지 없이 내용을 읽을 수 있고 자막·UI와 겹치지 않는지 확인.

### 수정 명령

```text
단어마다 다른 효과를 쓰지 말고 제한된 등장 규칙과 의미 강조만 남겨라.
```
