<a name="v2-01"></a>
## V2-01 · 하드 컷 (Hard Cut)

**Hard Cut** · PDF 65쪽

### 뜻·쓰임

전환 효과 없이 한 샷에서 다음 샷으로 즉시 바뀌는 편집이다. 리듬과 정보 전환을 가장 직접적으로 제어한다.

### 혼동 구분

거칠고 나쁜 편집을 뜻하지 않는다. dissolve가 많다고 연결이 부드럽거나 서사가 명확해지는 것은 아니다.

### 실행 명령

```text
손이 제품을 집는 동작 직후 디테일 샷으로 hard cut하라. 불필요한 디졸브를 없애고 행동의 방향을 유지하라.
```

### 설정·계약

컷 기준을 동작·발화·음악 비트 중 무엇에 둘지 정한다. 정확한 프레임과 소스 핸들을 확인한다.

### 검수

컷 앞뒤 동작이 중복·누락되거나 시선·화면 방향이 갑자기 뒤집히지 않는지 확인.

### 수정 명령

```text
효과를 추가하기 전에 컷 위치를 몇 프레임 앞뒤로 옮겨 연결을 비교하라.
```

<a name="v2-02"></a>
## V2-02 · J 컷·L 컷 (J-cut / L-cut)

**J-cut / L-cut** · PDF 65쪽

### 뜻·쓰임

J 컷은 다음 장면 소리가 화면보다 먼저 시작하고 L 컷은 이전 장면 소리가 다음 화면까지 이어지는 분리 편집이다. 대화·B-roll 연결을 자연스럽게 만든다.

### 혼동 구분

오디오를 무조건 겹치는 crossfade와 다르다. 어떤 장면의 소리가 먼저 또는 늦게 끝나는지 구별한다.

### 실행 명령

```text
다음 인터뷰 답변의 음성을 12프레임 먼저 들려주는 J-cut을 만들고, 이전 질문의 끝은 겹치지 않도록 정리하라.
```

### 설정·계약

12프레임은 예시다. 타임라인 FPS와 발화 호흡을 기준으로 길이를 조정하고 배경음의 연속성을 맞춘다.

### 검수

단어가 잘리거나 두 화자의 핵심 대사가 겹치지 않는지 이어폰과 스피커로 확인.

### 수정 명령

```text
‘소리 먼저’라는 말에 어떤 클립의 오디오인지 지정하고 정확한 선행 구간을 적어라.
```

<a name="v2-03"></a>
## V2-03 · 매치 컷 (Match Cut)

**Match Cut** · PDF 66쪽

### 뜻·쓰임

형태·움직임·구도·소리의 유사성을 이용해 두 장면을 연결하는 편집이다. 공간과 시간이 달라도 시각적 대응으로 의미를 만들 수 있다.

### 혼동 구분

같은 동작을 이어 붙이는 match-on-action과 관련되지만 동일하지 않다. 이름만 같아도 연결 대상이 불명확하면 임의 전환이 된다.

### 실행 명령

```text
원형 시계 클로즈업에서 같은 화면 위치·크기의 바퀴로 match cut하라. 중심과 회전 방향을 맞춰라.
```

### 설정·계약

대응시킬 형태·위치·속도·색을 선택한다. 두 소스의 프레이밍을 먼저 맞추고 컷 지점을 조절한다.

### 검수

전환 순간 핵심 형태가 같은 위치에서 읽히고 의도한 의미 연결이 전달되는지 확인.

### 수정 명령

```text
장면 전체를 억지로 비슷하게 만들지 말고 연결의 기준 형태 하나를 명확히 하라.
```

<a name="v2-04"></a>
## V2-04 · 점프 컷 (Jump Cut)

**Jump Cut** · PDF 66쪽

### 뜻·쓰임

비슷한 구도의 연속 샷에서 시간 일부를 제거해 대상이 건너뛰어 보이게 하는 편집이다. 발화 압축·리듬 강조에 쓸 수 있다.

### 혼동 구분

연속성 오류가 의도 없이 생긴 것과 구별해야 한다. 모든 침묵 제거가 자연스러운 점프 컷은 아니다.

### 실행 명령

```text
설명 영상의 중복 발화만 제거하고 문장 호흡은 남겨라. 같은 구도 점프가 과하면 관련 B-roll로 필요한 부분만 덮어라.
```

### 설정·계약

최소 호흡·손동작·발화 의미를 우선한다. 자동 무음 제거 임계값을 일괄 적용하지 않는다.

### 검수

문장의 뜻·억양이 바뀌거나 손이 순간 이동해 주의를 빼앗지 않는지 확인.

### 수정 명령

```text
말 사이를 전부 붙이지 말고 의미 단위의 여유와 자연스러운 호흡을 복구하라.
```

<a name="v2-05"></a>
## V2-05 · 리플 편집 (Ripple Edit)

**Ripple Edit** · PDF 67쪽

### 뜻·쓰임

클립 길이를 바꿀 때 뒤의 클립을 함께 당기거나 밀어 빈틈 없이 연결하는 편집이다. 전체 러닝타임이 달라질 수 있다.

### 혼동 구분

Rolling Edit는 맞닿은 두 클립의 경계를 움직여 전체 길이를 유지한다. 어떤 트랙이 따라 움직일지도 중요하다.

### 실행 명령

```text
첫 클립의 끝 8프레임을 ripple trim하고 이후 영상·자막·음악 기준점의 동기 유지 여부를 확인하라.
```

### 설정·계약

잠금·동기화 잠금·연결된 오디오·마커의 이동 정책을 지정한다. 고정 납품 길이가 있으면 변화량을 기록한다.

### 검수

뒤 클립에 빈 구간이 없고 자막·음악 큐가 잘못 남지 않는지 확인.

### 수정 명령

```text
전체 길이를 유지해야 했다면 ripple 대신 rolling 또는 다른 길이 보정 방식을 사용하라.
```

<a name="v2-06"></a>
## V2-06 · 롤링 편집 (Rolling Edit)

**Rolling Edit** · PDF 67쪽

### 뜻·쓰임

인접 두 클립의 편집점을 옮겨 한쪽을 늘리고 다른 쪽을 줄이는 처리다. 두 클립의 합계 길이와 뒤의 위치를 유지할 수 있다.

### 혼동 구분

Ripple과 달리 뒤 전체를 당기지 않는다. 소스의 사용하지 않은 프레임이 부족하면 이동에 제한이 생긴다.

### 실행 명령

```text
A/B 경계를 6프레임 뒤로 rolling edit하되 전체 광고 길이 15초와 뒤 음악 큐를 유지하라.
```

### 설정·계약

양쪽 소스 핸들을 확인하고 연결 오디오 처리 여부를 명시한다. 앞뒤 동작 연속성을 검토한다.

### 검수

전체 길이와 뒤 클립의 위치가 유지되며 양쪽 컷에 정지·중복 프레임이 없는지 확인.

### 수정 명령

```text
부족한 프레임을 임의 복제하지 말고 가능한 핸들 안에서 경계를 조정하라.
```

**함께 구분할 용어:** [리플 편집 / Ripple Edit](V2.md#v2-05)

<a name="v2-07"></a>
## V2-07 · B-roll·컷어웨이 (B-roll / Cutaway)

**B-roll / Cutaway** · PDF 68쪽

### 뜻·쓰임

주요 발화·행동을 보완하는 보조 영상과 다른 디테일로 잠시 전환하는 샷이다. 설명을 구체화하고 편집 연결을 가릴 때 쓰인다.

### 혼동 구분

관련 없는 분위기 영상으로 모든 컷을 덮는 것은 정보 전달을 약화시킬 수 있다. 실제 증거 영상과 연출 영상을 구분한다.

### 실행 명령

```text
제품 재질을 설명하는 문장에 표면·접합부 B-roll을 배치하고 발화와 보이는 디테일을 일치시켜라.
```

### 설정·계약

각 소스의 설명 대상·사용 구간·권리·실제/합성 여부를 기록한다. 주요 정보를 가리는 자막과 충돌하지 않게 한다.

### 검수

음성 내용과 이미지가 모순되지 않고 해당 기능이 실제 제품에 존재하는지 확인.

### 수정 명령

```text
예쁜 장면을 늘리기보다 각 문장이 설명하는 구체적 대상을 보여 줘라.
```

<a name="v2-08"></a>
## V2-08 · 타임랩스 (Time-lapse)

**Time-lapse** · PDF 68쪽

### 뜻·쓰임

긴 시간의 변화를 짧게 재생하는 표현이다. 일정 간격으로 촬영한 사진을 연결하거나 영상을 가속해 만든다. 생성기는 실제 장시간 기록이 아니라 시간 압축의 모습을 합성할 수 있다.

### 혼동 구분

타임랩스는 긴 시간의 압축이다. 촬영 간격과 재생 FPS를 지정해야 실제 압축 배율을 계산할 수 있다.

### 실행 명령

```text
Locked-off time-lapse of clouds crossing a mountain valley, compressed passage of time, stable terrain and consistent framing.
```

### 설정·계약

실촬영 예: 5초마다 1장, 30fps 재생이면 약 150배 시간 압축이다. 노출·화이트밸런스를 고정하면 플리커를 줄이기 쉽다. 지형 고정과 구름 이동을 구분해 요청한다.

### 검수

구름·그림자 변화가 자연스럽고 산·건물 같은 고정 구조가 흔들리거나 자라지 않는지 확인.

### 수정 명령

```text
고정 건물의 변형을 줄이고 구름·그림자처럼 변해야 할 요소만 움직이게 하라.
```

<a name="v2-09"></a>
## V2-09 · 슬로 모션 (Slow Motion)

**Slow Motion** · PDF 69쪽

### 뜻·쓰임

동작을 실제보다 느리게 재생하는 표현이다. 고속 촬영을 낮은 재생 FPS로 해석하거나 프레임 보간으로 만든다. 생성 요청의 slow motion은 실제 고속 촬영 데이터 확보와 동일하지 않다.

### 혼동 구분

슬로 모션은 고속 소스·속도 해석·보간 중 어떤 방식인지 구별한다. 느린 움직임 외형만으로 촬영 FPS를 알 수 없다.

### 실행 명령

```text
Slow-motion splash of clear water, coherent droplets, crisp subject and a controlled camera; motion unfolds smoothly over the shot.
```

### 설정·계약

120fps 촬영을 24fps로 재생하면 5배 느려진다. 24fps 원본을 단순 감속하면 끊김이 커질 수 있다. 보간은 빠른 팔다리·물방울·가림 경계에 합성 오류를 만들 수 있다.

### 검수

접촉 순간과 겹친 물체 주변을 프레임 단위로 보고 보간 찢어짐을 확인.

### 수정 명령

```text
보간된 물방울·손가락이 찢어지면 해당 구간의 보간 방식을 바꾸거나 속도 변화를 줄여라.
```

<a name="v2-10"></a>
## V2-10 · 스피드 램핑 (Speed Ramping)

**Speed Ramping** · PDF 69쪽

### 뜻·쓰임

한 클립 안에서 재생 속도를 시간에 따라 변화시키는 편집이다. 특정 순간을 강조하거나 이동 구간을 압축할 때 쓰인다.

### 혼동 구분

일정 속도의 slow motion·time-lapse와 다르다. 속도가 변하면 클립 길이와 오디오 처리도 바뀐다.

### 실행 명령

```text
달리는 장면을 초반 100%, 착지 순간 40%, 이후 150%로 변화시키고 전환 구간은 부드럽게 보간하라.
```

### 설정·계약

속도값·기준 시점·오디오 유지/분리·보간 방식을 정한다. 소스 FPS가 허용하는 감속 범위를 검토한다.

### 검수

가속·감속 경계의 발 미끄러짐, 오디오 피치, 전체 길이 변화를 확인.

### 수정 명령

```text
비트에 억지로 맞추지 말고 동작의 힘이 실리는 순간을 기준으로 램프 위치를 조정하라.
```
